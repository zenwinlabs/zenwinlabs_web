Frequently Asked Questions

Does NetWorth require an internet connection?

No. NetWorth works entirely offline. There are no servers, no syncing, and no network requests. The app works in airplane mode and will continue to work without any internet access, indefinitely.

Do I need to create an account?

No. There are no accounts. You open the app and start logging. No email address, no password, no sign-up of any kind.

Where is my data stored?

On your device only. NetWorth stores your data in a local database that no other app — and no one at ZenWinLabs — can access. When you delete the app, the data is gone.

How do I back up my data?

Go to Settings → Data → Export as JSON backup. This creates a complete backup file of all your assets, debts, goals, and history. Save it anywhere — your files app, Google Drive, email — wherever you choose.

How do I restore my data on a new phone?

Transfer your JSON backup file to your new device, then open NetWorth and go to Settings → Data → Restore from backup. Select your backup file and confirm. All your data will be restored exactly as it was.

What is EMI auto-reduce?

When you add a debt, you can enter your monthly EMI amount and due date. If you turn on "auto-reduce," NetWorth automatically creates a payment log entry on that date each month and updates your outstanding balance — so you don't need to manually log every EMI payment.

How do goal projections work?

When you create a goal, you can set an expected annual growth rate (for example, 12% for a mutual fund). NetWorth uses this to draw a projected trajectory line on the goal's graph — showing you where your money should be at any given point. Your actual logged values always take priority over the projection. The projection is just a reference line, not a prediction.

Can I link the same asset to multiple goals?

Yes. You can link any asset to any number of goals, and you control what percentage of that asset's value counts toward each goal. If an asset is already linked to another goal, NetWorth will show you the overlap so you're aware — but it won't block you from linking it again.

Why can't I see my changes on the graph after logging an update?

Make sure the date you entered for the log entry falls within the graph's selected period. If you logged a value with a date from 6 months ago but the graph is set to "1M," that point won't be visible. Switch the period to "All" to see all data points.

How do I delete an asset, debt, or goal?

Open the detail screen for the item, tap the overflow menu (⋮), and select Delete. You'll be asked to confirm. Deleting an asset or debt also deletes all its log history permanently.

Is there a web version or iOS version?

NetWorth is currently available on Android only. There is no web version, iOS version, or desktop version.
